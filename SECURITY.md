# Security policy

## Supported versions

Security fixes go into the latest release on [PyPI](https://pypi.org/project/khatt/).

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/DrEssam97/khatt/security/advisories/new)
instead. You'll get a reply within a week.
